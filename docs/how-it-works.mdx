The project is organized around a protocol for recording findings and a voting system for community coordination. Their separation lets each part evolve independently. See [Project State](/project-state) for the current alpha status and limitations.

## Recording findings

The protocol records observations using the Darwin Core standard. The current test interface includes a **“Not a real finding”** option: those entries are marked as test data and stored separately from real findings.

## Voting and coordination

The voting stack contains the voting logic and is built on Agora and [LiquidDAO](/concept/liquid-dao). The protocol and voting system are separate components.

## The hook

A hook connects the protocol to the voting system. Keeping this connection explicit allows either component to change without requiring the other to become the same system.

## Free tools

The project provides free tools for working with data locally and, as the registry develops, for connecting findings to it. The tools section of the repository contains the current implementation.

## Planned architecture

The documented direction is to use Base for day-to-day project activity and Ethereum mainnet for a permanent registry of verified findings. The current prototype runs on Sepolia; moving to this planned architecture is future work.
