# Documentation

## Mintlify site

The public project documentation for Mintlify is in [`mintlify/`](mintlify/). Its `docs.json` is the Mintlify configuration, with the site pages, navigation, logo, and favicon alongside it.

When connecting this repository in Mintlify, set the documentation directory to `docs/mintlify`. Keep internal engineering notes and project implementation documents outside that directory.

To preview locally, run the Mintlify CLI from `docs/mintlify`.
