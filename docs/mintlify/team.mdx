Darwin Core Protocol is built by **one person**. This is deliberate, and it is one of the project's strengths.

## A pure non-profit

There are no returnable investments, no fees and no paid offers. The project is a **pure non-profit**, and that is exactly why it is built, and will keep being built, by one person.

It is also **zero-asset**: there is no token and there never will be, so nothing in the project can be speculated on.

## No roadmap

There is no roadmap. That sounds strange, but it is what lets the project survive anything: whether there is money or not, users or not, problems or not. Nothing in the project depends on a promise made to someone else.

## Working alone is the key, not the problem

A project run by one person has no coordination overhead, no conflicting incentives and nobody to run out of patience. That makes it **very resilient and able to play a very long game**.

## How it is built

I write the **contract code myself**. Everything else, such as the app, the documentation and the tools, is built mostly with the help of AI.

This is deliberate. The contracts are the heart of the project, not its shell. Writing them by hand lets me control every security detail afterwards and know exactly what happens where.
