# Project Texts

This directory contains engineering notes, integration plans, reviews, and other project documents that are maintained separately from the public Mintlify documentation in [`../docs/`](../docs/).

The Mintlify configuration is [`../docs/docs.json`](../docs/docs.json). Connect this repository to Mintlify using `docs` as its documentation directory. To preview locally, run the Mintlify CLI from `docs/`.
