Detectar registros de presencia duplicados

Compara los campos elegidos, inspecciona los grupos y decide qué registros conservar. No se elimina nada automáticamente.

Cómo funciona +
  1. Elige un archivo local, pega una tabla o prueba el ejemplo sintético.
  2. Revisa los ajustes y ejecuta el procesamiento.
  3. Inspecciona el resultado y descarga CSV, XLSX, un informe o una receta.

Privacidad y límites

Los datos permanecen en esta sesión del navegador. No hay cuentas, suscripciones, cargas al servidor ni publicación. El alojamiento puede registrar las solicitudes habituales de páginas.

Admite CSV, TSV y una hoja XLSX cada vez. Esta versión no incluye XLS antiguos, macros, verificación científica ni correspondencias taxonómicas.
