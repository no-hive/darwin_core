Darwin Core Workflow Builder

Combine column mapping, date normalization and duplicate review in any order. Add or repeat steps, inspect the result and export a reusable recipe.

How it works +
  1. Choose a local file, paste a table or try the synthetic sample.
  2. Review the settings and run processing.
  3. Inspect the result, then download CSV, XLSX, a report or a recipe.

Privacy and limits

Data stay in this browser session. There is no account, subscription, upload endpoint or publication flow. A standard page request may still be logged by the host.

Supports CSV, TSV and one XLSX worksheet at a time. Legacy XLS, macros, scientific verification and taxonomic matching are outside this release.
